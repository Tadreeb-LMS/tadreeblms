## 🔧 Description

This PR introduces asynchronous KPI data export with automatic download behavior and improves KPI page action button visibility while preserving the existing site theme.

### Problem Solved

Previously:

- KPI export flow could fail with file write permission issues when writing directly under public path.
- Export completion required a manual click on a download link.
- KPI top action buttons had low visual prominence and were hard to scan quickly.

### What This PR Adds

- Async KPI export flow with queued processing and persistent export status tracking.
- CSV and XLSX export support for KPI metrics.
- Export filters by:
  - role
  - date range
  - specific KPIs
- Export progress polling API and UI feedback in KPI Management.
- Automatic file download trigger when export status reaches completed (no manual link click required).
- Safer file storage for generated exports using Laravel public storage disk (`storage/app/public/reports`) and public URL under `/storage/reports`.
- Improved top KPI action button visibility with theme-consistent styling (better contrast/hover/focus states).

Fixes: https://github.com/Tadreeb-LMS/tadreeblms/issues/429
